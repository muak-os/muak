# Reporting Security Issues

We take security bugs in Muak seriously. We appreciate your efforts to responsibly disclose your findings, and will make every effort to acknowledge your contributions.

To report a security issue, please use the GitHub Security Advisory ["Report a Vulnerability"](https://github.com/muak-os/muak/security/advisories/new) tab.

We will send a response indicating the next steps in handling your report. After the initial reply to your report, we will keep you informed of the progress towards a fix and full announcement, and may ask for additional information or guidance. The expected response time is within 3 business days, and the fix is expected to be delivered within 30 days.

## Supported Releases

We will only provide security updates for the two latest minor releases of Muak. If you are using an older version, we recommend upgrading to the latest release.

For example, if the latest release is `v0.2.3`, the supported releases are `v0.1.x` and `v0.2.x`.
